# S1.1 — Extraction bake-off on the supplied sources

Run on 23 Nov 2026 with ai-svc's extraction (`ai/app/extract/`), Tesseract 5.3.4 (`ara+eng`, default models), pages rendered at 300 dpi, CPU only. Reproduce with `ai/` and the PDFs in the repo root. Synthetic data was not needed: these are public regulations.

| Source | Damage found | Example |
|---|---|---|
| نظام مزاولة المهن الصحية (current, 1440) | «لا» ligature extracted as «ال» | «الئحة»، «خالل»، «إال»، «االشتراطات» |

| Job description (GP) | Arabic header lines with letters reversed inside each word; English body clean | «ةكلمملا ةيبرعلا» |

## Method per page (automatic)

1. **Text layer sound** → use it (reversed lines fixed word by word).
2. **Only the ligature is damaged** → OCR the page and **repair the text layer with the OCR words**: every word containing «ال» is tried with «لا» instead, and the variant OCR actually read wins (exact match, else fuzzy ≥ 85, plus a small seed list of frequent words). The text layer keeps its exact letters; OCR supplies the ligature.
3. **Encoding damage** (detected two ways: mid-word «ى», or words that match an OCR word once the known letter swaps are undone, above 4% of the page) → use the OCR text.
4. **OCR worse than the layer** (mean confidence < 0.75, e.g. forms with dotted fields) → keep the repaired layer.
5. Optional for public sources only: **Claude page transcription** (`mode=llm_transcription`, prompt `kb-transcribe-v1`).

Thresholds were set from measurements on these files: encoding-damage share was ≤ 0.03 on all checked pages of the law and ≥ 0.06 on all checked pages of the dental regulation.

## Recommendation (decision D5)

- **Law (both editions):** repaired text layer, as planned. The older edition is indexed as archived (D25).
- **Dental services regulation:** Tesseract OCR is good enough to index now (confidence 0.91, clean on the pages checked). Claude transcription (the plan's primary path for this source) stays available as `mode=llm_transcription` and costs about $0.01–0.02 per page; use it if the lawyer's spot-check (S1.6) finds OCR errors that matter.
- **Known gaps for the lawyer's spot-check (S1.6):** article 33 of the older edition; regulation paragraph numbering is taken from the article it sits under (`27/1`), because the printed numbers («1-2») don't follow the article numbers consistently; definitions in article 1 split into 2 terms only.
- **Case documents (D6):** the same extraction runs on uploads; Tesseract by default. PaddleOCR stays the alternative if scanned or photographed letters (W4) read badly.
